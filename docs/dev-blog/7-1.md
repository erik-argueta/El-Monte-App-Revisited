## Breakdown
The Home Screen will display a vertical grid of the following buttons: `Resources`, `How Do I...`, `For Residents`, `Business Related`, `Government Related`, and `Services`  
With the repettitive nature of the grid, I knew it would be best to implement a reusable widget for the buttons. 

## homescreen_grid.dart breakdown  
For customization of the tiled button, I would need to pass the following necessary parameters: `Icon`, `Label`; Claude.ai generated the widget to also accept an `Icon Color`, but I am not so concerned with that right now.  

It begins with establishing the class `HomeGridButton` and states what is required to use the widget using `required` and `this.` for the members of the widget.  

```dart
class HomeGridButton extends StatelessWidget {
  final IconData icon;
  final String label;
  final Color iconColor;
  final VoidCallback onTap; // a function with no return value, called on tap

  const HomeGridButton({
    required this.icon,
    required this.label,
    required this.onTap,
    this.iconColor = Colors.teal, // default value if not specified
    super.key,
  });

```  

The body of the widget returns InkWell for visual tap feedback and its ability to handle onTap. Its child is a custom `Container` with its decoration established through `BoxDecoration`.  
The `Container`'s child is a `Column` with the children having to do with the `Icon`, `Label`, and general style for the button.
